# CNN-Gender
# Gender Detection using CNN

This project detects gender (man/woman) using a Convolutional Neural Network (CNN) built with TensorFlow and Keras. The model is trained on face images and used to predict gender in real-time through a webcam.

## Files

- `trainer.py` – Trains the CNN model using image data (man/woman).
- `VideoTester.py` – Uses webcam to detect faces and predict gender in real time.


## Requirements

- Python
- TensorFlow
- OpenCV
- NumPy
- cvlib

Install dependencies using:

pip install tensorflow opencv-python numpy cvlib
